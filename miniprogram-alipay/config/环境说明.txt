# 支付宝小程序 — 环境配置说明
# ═══════════════════════════════════════════════════════════════
# 主配置：config/env.js（仅 API 地址等）
# 隐私开关：项目根 .env（经 /miniprogram/config 下发，改后重启后端）
#   ENABLE_ALIPAY_AVATAR / ENABLE_ALIPAY_NICKNAME / ENABLE_ALIPAY_PHONE_BIND
# ═══════════════════════════════════════════════════════════════

【个人主体测试】
  ENABLE_ALIPAY_AVATAR=true
  ENABLE_ALIPAY_NICKNAME=true
  ENABLE_ALIPAY_PHONE_BIND=false   ← 个人无法申请一键取号，手输手机号

【企业正式】
  三项均可 true（须开放平台隐私政策 + 已开通「获取会员手机号」）

【改局域网 IP】
  config/env.js → DEV_LAN_HOST
