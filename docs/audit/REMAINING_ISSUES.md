## 2. P1 级遗留（建议近期排期）

### P1-R1 限流 fail-closed 开关
- 现状：[rate_limit.py:74-77](file:///e:/SmartNoodleHouse/backend/app/core/rate_limit.py) Redis 宕机统一 fail-open（降级放行），由业务多层防护兜底。
- 风险：Redis 故障窗口内登录/支付端点失去限流，存在撞库/爆破的理论风险。
- 建议：增加配置（如 `RATE_LIMIT_FAIL_CLOSED_PATHS=/api/auth/login,/api/payments/`），仅对敏感端点 fail-closed 返回 503，其余维持 fail-open。
- 注意：改动需同步更新 [测试_限流关闭失败.py](file:///e:/SmartNoodleHouse/tests/测试_限流关闭失败.py) 与 [测试_消息幂等与域模块.py](file:///e:/SmartNoodleHouse/tests/测试_消息幂等与域模块.py) 两处预期。

### P1-R2 数据库自动备份与恢复演练
- 现状：仓库仅提供初始化/对账脚本，无自动备份与恢复验证流程。
- 建议：每日全量 + binlog 增量；至少季度在隔离环境演练一次恢复；验证备份可恢复性而非仅"备份成功"。

### P1-R3 真实 MySQL 持续集成
- 现状：全部 DB 测试跑 SQLite in-memory，无法覆盖 MySQL 方言差异（部分 CHECK、`SKIP LOCKED`、索引 DDL、utf8mb4 排序规则）。
- 建议：CI 增加 MySQL 8 service container，对资金/库存/锁相关测试加 MySQL 标记并在流水线执行。

### P1-R4 支付渠道 T+1 自动对账
- 现状：PaymentLedger 与财务台账完整，但无银行/支付渠道对账文件下载与差异核对 job。
- 建议：实现微信/支付宝对账账单解析，T+1 比对本地台账，差异（长款/短款/手续费）生成对账差异工单。

### P1-R5 全链路压测与容量基线
- 现状：仅有推荐模块性能基准，无整体 TPS/慢查询/连接池水位报告。
- 建议：对午晚高峰核心链路（下单/支付回调/KDS/查询）压测，固化 worker 数、连接池、DB max_connections 的容量公式。

### P1-R6 历史订单冷库归档
- 现状：30 天以上订单仅 PII 脱敏，仍留在热表，长期增长影响查询与备份窗口。
- 建议：按年度/季度归档到冷库或分区表，热表保留近 6–12 个月，提供归档查询入口。

## 3. P2 级遗留（功能完善 / 可维护性）

### P2-R1 前端自动化测试缺失
- 现状：frontend（Vue3 + TS + Element Plus）无单元/E2E 套件；路由守卫、401 分流、分页/筛选联动仅人工与后端联调验证。
- 建议：引入 Vitest（store/api 单测）+ Playwright（登录/下单/退款关键路径 E2E）。

### P2-R2 大表在线 DDL 工具
- 现状：0007 迁移靠 MySQL 8 在线 DDL + information_schema 幂等检查。
- 建议：超大型表使用 pt-online-schema-change 或 gh-ost，纳入发布手册。

### P2-R3 字段级权限
- 现状：权限为端点 + 门店级，收银员可经后端读取到部分敏感字段（如成本价，取决于具体端点）。
- 建议：在序列化层引入字段级权限控制，按角色裁剪成本/毛利等字段。

### P2-R4 角色可视化编辑
- 现状：RBAC 表结构（Role/RolePermission/Permission）完整，但管理后台主要使用预置角色，自定义角色编辑器能力有限。
- 建议：提供角色-权限矩阵 UI 与变更审计。

### P2-R5 临时授权 / 委派
- 现状：不支持店长休假期间临时授权。
- 建议：增加 RoleDelegation（委托人、被委托人、权限集、有效期），到期自动回收。

### P2-R6 分库分表 / 读写分离预案
- 现状：单库设计满足当前连锁规模。
- 建议：订单与流水表按 store_id/time 预留分片键评估；报表查询可走只读副本。

### P2-R7 JWT 算法演进
- 现状：JWT HS256 对称签名，密钥仅在后端，当前可接受。
- 建议：若未来拆分为多个独立服务或引入第三方网关，迁移到 RS256/EdDSA 非对称签名，降低密钥分发风险。

### P2-R8 测试桩 warning 治理
- `测试_智能推荐_12性能治理.py` 使用废弃的 `starlette.testclient`（建议迁 httpx2）。
- `测试_支付退款.py` outbox `begin_nested` mock 存在未 await 协程告警（不影响断言，建议收紧）。
