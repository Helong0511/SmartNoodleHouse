# 数据库设计与迁移规范

> 当前代码基线：main @ 442beb4761b29f5b415830e91e06c97241f74ef3。结构细节以 sql/struct.sql 的 CANONICAL SCHEMA、Alembic 当前 head、ORM 模型和 scripts/验证数据库.py 共同核验；发生差异时先停止发布并查明唯一真源。

## 1. 数据库操作安全警告

**sql/struct.sql 是破坏性初始化脚本：包含 DROP DATABASE IF EXISTS。sql/data_sys.sql 含业务表 TRUNCATE。不得对任何已有业务数据的数据库执行这两个文件。**

- 全新空库：仅在确认目标库为空、已完成备份/恢复策略、隔离环境演练和双人确认后，按初始化说明执行。
- 已有库/生产库：只通过 Alembic 迁移升级；执行前备份并在同版本 MySQL 预生产演练。
- data_test.sql：仅测试环境。
- 不得把 README 中的初始化 SQL 复制到生产日常发布脚本。

## 3. 主要业务域

- 身份与权限：users、roles、permissions、role_permissions、operation_logs。
- 门店与桌台：stores、tables、store_settings。
- 商品库存：products、product_categories、规格、门店库存及库存流水。
- 订单支付：orders、order_items、payments、payment_refunds、回调回执、状态历史。
- 财务：financial_ledger，按门店和业务单据记录 SALE/REFUND/ADJUSTMENT。
- 会员营销：customers、member_levels、coupon_templates、customer_coupons、point_ledger、积分兑换配置、营销活动与门店参与关系。
- 外卖：平台门店绑定、商品/分类映射、外卖订单、退款与回调日志。
- 异步可靠性：webhook_inbox、outbox_events、打印任务、重试状态。
- 人脸迎宾：摄像头、访客抓拍、授权、人脸特征密文及审计。

## 4. 关键数据库不变量

- 订单、支付、退款、财务流水有稳定唯一业务标识和幂等约束。
- 库存/名额使用条件 UPDATE 与唯一约束防超卖；不依赖先 SELECT 后 UPDATE。
- 门店相关表有明确 store_id、外键/索引；所有查询均执行服务端租户范围过滤。
- 支付回执、外卖事件、Outbox/Inbox 有唯一键、状态、尝试次数、租约/锁字段和可回收机制。
- 金额使用 Decimal/定点精度；订单、支付、退款、台账金额之间可核对。
- 字符集统一 utf8mb4；所有连接、导入和迁移验证中文数据。
- 生产迁移避免长时间锁表；大表 DDL 必须先评估执行计划、锁时间和回滚策略。

## 5. 生产迁移流程

1. 确认 commit SHA、目标数据库、当前 alembic_version 和 MySQL 版本。
2. 完成 mysqldump/物理备份，并验证备份可读取；重要发布先在隔离库完成恢复演练。
3. 在同版本 MySQL 预生产环境执行 alembic upgrade head。
4. 对比迁移前后表、字段、索引、外键、唯一约束和数据行数。
5. 执行关键业务回归：下单、支付回调、退款、库存并发、门店隔离、Outbox。
6. 生产低峰期执行迁移，观察锁等待、慢查询、连接池和错误率。
7. 运行 scripts/验证数据库.py，检查 readiness 和业务抽样。
8. 记录迁移日志、执行人、耗时、commit 和回滚/前滚方案。

## 6. 初始化与升级命令边界

已有库升级：
```bash
cd backend
alembic upgrade head
python ../scripts/验证数据库.py
```

全新空库初始化脚本见 scripts/生产部署-ubuntu.txt 中专门的空库流程。不得把 DROP/TRUNCATE 初始化脚本加入自动发版流水线。任何 destructive migration 必须加目标环境保护、备份、确认标记和审批。

## 7. 数据完整性与测试

- SQLite 适合快速单元测试，不足以验证 MySQL 行锁、SKIP LOCKED、隔离级别、DDL、索引和外键行为。
- 关键迁移必须在 CI 的 MySQL 8 job 和预生产同版本数据库验证。
- 并发测试覆盖库存、秒杀、优惠券、支付回调、退款和同一幂等键。
- 对账验证 payments、refunds、orders、financial_ledger、积分/券副作用的一致性。
- 备份恢复测试恢复到隔离库，检查外键、唯一键、字符集、行数及业务抽样。
