## Task 3: 后端 API — 边缘代理接口

**Status:** pending  
**Priority:** high  
**依赖：** Task 2

- 新建 `backend/app/api/v1/edge.py`：

  - 验证 `X-Edge-Api-Key` 与 `EdgeAgent.api_key_hash` 匹配
  - 注入对应 `store_id`

**AC 映射：** FR-2, FR-3, FR-6

**Test Requirements (rule):**
- 无 API Key 返回 401
- 错误 API Key 返回 403
- 正确 API Key 返回 200 并正确关联 store_id
- 图像大小超限返回 413
- `face-profiles` 接口返回加密特征向量和 label/customer 信息

## Task 6: 边缘代理 — 人脸识别与匹配

**Status:** pending  
**Priority:** high  
**依赖：** Task 3, 5

**内容：**
- `edge/edge_recognition.py`：
  - `EdgeRecognitionWorker`：从帧缓冲取帧，检测人脸，提取 embedding
  - `FaceMatcher`：与本地缓存特征库做余弦相似度匹配
    - 阈值 `FACE_MATCH_THRESHOLD`（默认 0.75）
    - 多帧确认（连续 N 帧匹配同一人才触发）
  - 匹配成功 → 触发 TTS 回调
  - 匹配失败 → 检查去重冷却 → 推送未匹配人脸到中央服务器
- `edge/edge_cache.py`：
  - 本地特征库缓存（内存 dict），支持增量更新
  - 未匹配人脸去重冷却（同摄像头 60s 内不重复推送同一 embedding 区域）
  - 离线事件缓存（SQLite）：断网时暂存未匹配事件

**AC 映射：** FR-1(3,4,5,6), NFR-1, NFR-2

**Test Requirements (rule):**
- FaceMatcher 在相似度高于阈值时返回匹配结果
- 多帧确认逻辑正确（连续 N 帧才触发）
- 去重冷却生效（60s 内同一人脸不重复推送）
