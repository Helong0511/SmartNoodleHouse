# 五、修复手机号验证漏洞

重点检查：

```text
backend/app/api/v1/miniprogram.py
```

以及所有：

```text
phone
phone_code
alipay_phone_encrypted
phone_verified
```

当前存在严重风险：

用户自己输入：

```json
{
  "phone": "13800138000"
}
```

不能被认为手机号已经验证。

必须严格区分：

## 未验证手机号

```text
phone_verified = 0
```

## 微信官方手机号授权

必须：

```text
phone_code
↓
微信官方接口
↓
服务端验证
↓
获得手机号
↓
phone_verified = 1
```

## 支付宝手机号授权

必须：

```text
支付宝授权数据
↓
服务端验证/解密
↓
获得手机号
↓
phone_verified = 1
```

用户手动填写手机号：

```text
只能保存为未验证
不能自动认证
不能自动合并账号
```

# 六、彻底修复手机号自动合并账号问题

重点检查：

```text
CustomerService.try_link_by_phone()
CustomerMergeService
```

禁止：

```text
用户输入手机号
↓
直接发现已有 Customer
↓
自动合并
```

正确流程：

```text
微信/支付宝身份
        ↓
获得官方可信手机号
        ↓
phone_verified = true
        ↓
查找已有 Customer
        ↓
如果没有
    ↓
绑定手机号

如果已有其他 Customer
    ↓
进入账号合并流程
    ↓
获取必要的用户确认
    ↓
事务锁
    ↓
合并
    ↓
迁移允许迁移的数据
    ↓
旧 Token 全部失效
    ↓
重新签发 Token
```

必须防止：

```text
账号接管
身份冒用
错误合并
手机号碰撞
并发合并
重复合并
合并死锁
```
