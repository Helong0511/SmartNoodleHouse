### 1.2 后端代码侧已完成项

- [ ] app.json 隐私配置只是声明，不等于授权生命周期已经正确运行；需真机验证授权弹窗、拒绝、撤回、再次授权与接口调用前置检查。
- [x] `privacy-popup` 组件已接入首页和会员页
- [x] 已使用 `open-type="agreePrivacyAuthorization"` 官方同意按钮
- [ ] 微信与支付宝隐私 API 必须分别按各自官方文档和正式基础库验证；不可将微信 API 名称/行为直接视为支付宝实现已完成。2026-11-08 审查发现支付宝端隐私 API 可能为空操作，未完成真机验证前不得勾选通过。
- [x] 扫码后**静默直入菜单**（无注册墙）：绑桌与登录并行、12 秒弱网兜底，游客可浏览点餐
- [x] 手机号防冒用：注册/激活接口不收手机号；`/member/phone` 生产仅接受官方授权凭据，手输/`mock:debug` 仅开发环境允许（未验证保存、不合并账号）
- [x] 调试入口（模拟一键授权/手输手机号）**仅开发版显示**，体验版与正式版自动隐藏（符合"不得出现开发调试入口"审核要求）

- [x] 已删除空的 `face` 页面（微信）

### 1.3 本项目使用的隐私 API 清单

| 能力 | 微信 API | 支付宝 API | 需在隐私协议声明 |
|---|---|---|---|
| 头像 | `chooseAvatar` | `chooseAvatar` / `getOpenUserInfo` | 收集你的头像 |
| 昵称 | `type="nickname"` 输入框 | 昵称输入 / `getOpenUserInfo` | 收集你的昵称 |
| 手机号 | `getPhoneNumber`（返回 code，后端换号） | `getPhoneNumber`（返回授权密文，后端 AES 解密） | 收集你的手机号 |
| 相册/相机 | `chooseMedia` / `chooseImage` | `chooseImage` | 收集你的相册信息、摄像头信息 |
| 扫码 | `scanCode` | `scan` | 收集你的摄像头信息 |
| 剪贴板 | `getClipboardData` | — | 收集你的剪贴板信息 |

### 1.4 手机号能力与调试链路

| 环境 | 行为 |
|---|---|
| 生产 + 企业认证 + `ENABLE_*_PHONE_BIND=true` | 官方一键授权真实取号，验证后可合并历史账号 |
| 生产 + 能力未开通/未认证 | 会员页提示"暂未开通，不影响点餐"；后端拒绝一切非官方凭据（40054） |
| 开发环境（`APP_ENV=development`） | 额外开放两条调试链路（仅开发版小程序可见入口）：①模拟一键授权（`mock:debug` 凭据，固定测试号 13800000000）②手输手机号；均保存为**未验证**、不合并账号 |
| 体验版（提审用） | 调试入口自动隐藏，与正式版一致 |

> ⚠️ 微信 `getPhoneNumber` 需非个人主体且完成微信认证，按次计费（0.03 元/次，含 1000 次体验额度）；支付宝 `getPhoneNumber` 已免申请，但敏感会员信息不对个人账号开放。

## 2. 微信小程序后台配置

登录地址：https://mp.weixin.qq.com

### 2.1 基本信息

路径：**设置 → 基本设置**

| 配置项 | 填写内容 |
|---|---|
| 小程序名称 | 智能面馆（或品牌名+"面馆"） |
| 小程序简称 | 面馆 |
| 小程序头像 | 上传 144×144 PNG，≤ 200KB |
| 小程序简介 | 一句话描述功能，如"扫码点餐、会员口味记忆、智能推荐"（10–32 字） |
| 服务类目 | 餐饮 → 餐饮服务（需上传食品经营许可证） |

> ⚠️ 个人主体无法开通微信支付和手机号快速验证，请使用企业/个体工商户主体。

### 2.2 开发设置

路径：**开发 → 开发管理 → 开发设置**

#### 2.2.1 服务器域名（关键）

| 域名类型 | 填写值 |
|---|---|
| request 合法域名 | `https://your-domain.com` |
| uploadFile 合法域名 | `https://your-domain.com` |
| downloadFile 合法域名 | `https://your-domain.com`（如使用 CDN 则填 CDN 域名） |
| socket 合法域名 | `wss://your-domain.com`（如使用 WebSocket） |

> 必须 HTTPS，域名需已 ICP 备案。每月可修改 5 次。

#### 2.2.2 业务域名

如未使用 `web-view` 组件则无需配置。本项目未使用 `web-view`，跳过。

### 2.3 用户隐私保护指引（关键）

路径：**设置 → 服务内容声明 → 用户隐私保护指引**

点击"更新"，逐项勾选并填写用途说明：

| 收集的信息 | 用途说明（参考） |
|---|---|
| 用户信息（头像） | 用于会员头像展示 |
| 用户信息（昵称） | 用于会员昵称展示 |
| 手机号 | 用于会员账号绑定与订单通知 |
| 相册信息 | 用于会员头像上传（从相册选择） |
| 摄像头信息 | 用于扫码点餐桌台码绑定、头像拍摄 |
| 剪贴板信息 | 用于识别剪贴板中的桌台码链接 |

提交后等待审核，通常 10 分钟–2 小时生效。生效前 `chooseAvatar` / `getPhoneNumber` 会报隐私未声明错误。

### 2.4 微信支付

路径：**微信支付 → 接入微信支付**

1. 开通微信支付商户号，完成商户认证
2. 在商户平台 API 安全中：
   - 设置 APIv3 密钥（32 位）
   - 申请 API 证书，获取商户证书序列号
3. 配置支付回调地址：`https://your-domain.com/api/payments/wechat/notify`
4. 退款回调地址（如启用退款）：`https://your-domain.com/api/payments/wechat/refund-notify`

后端 `.env` 对应配置：
```
WECHAT_APP_ID=wxd0964c5d02b1549d
WECHAT_APP_SECRET=你的小程序密钥
WECHAT_MCH_ID=商户号
WECHAT_API_V3_KEY=APIv3密钥
WECHAT_CERT_SERIAL_NO=商户证书序列号
WECHAT_PRIVATE_KEY_PATH=certs/wechat_apiclient_key.pem
WECHAT_PLATFORM_CERT_PATH=certs/wechat_platform_cert.pem
WECHAT_NOTIFY_URL=https://your-domain.com/api/payments/wechat/notify
```

### 2.5 订阅消息（可选）

2. 添加并记录模板 ID
3. 后端 `.env` 配置：`WECHAT_SUBSCRIBE_TEMPLATE_ORDER_READY=模板ID`

2. mp 后台 → 版本管理 → 提交审核

## 3. 支付宝小程序后台配置

登录地址：https://open.alipay.com

### 3.1 基本信息

路径：**控制台 → 小程序 → 基本信息**

| 配置项 | 填写内容 |
|---|---|
| 小程序名称 | 3–20 字符，与微信端保持一致 |
| 小程序图标 | 180×180，PNG/JPG，≤ 120KB，圆角 12px |
| 小程序简介 | 10–32 字，描述核心功能 |
| 服务类目 | 餐饮 → 餐饮服务（上传食品经营许可证） |

### 3.2 服务器域名白名单（关键）

路径：**控制台 → 小程序 → 开发设置 → 服务器域名白名单**

| 配置项 | 填写值 |
|---|---|
| 域名 | `https://your-domain.com` |

> 支付宝只需要配置一个域名白名单，覆盖 request / uploadFile / downloadFile。

### 3.3 接口加签方式（关键）

路径：**控制台 → 小程序 → 开发设置 → 接口加签方式**

1. 选择"公钥"模式
2. 生成应用私钥（PKCS8 格式）和应用公钥
3. 将应用公钥上传到平台，获取**支付宝公钥**
4. 配置"接口内容加密"（AES 密钥），用于手机号等敏感信息解密

后端 `.env` 对应配置：
```
ALIPAY_APP_ID=你的支付宝AppID
ALIPAY_PRIVATE_KEY=-----BEGIN PRIVATE KEY-----\n...\n-----END PRIVATE KEY-----
ALIPAY_PUBLIC_KEY=支付宝公钥
ALIPAY_AES_KEY=接口内容加密AES密钥
ALIPAY_GATEWAY=https://openapi.alipay.com/gateway.do
ALIPAY_NOTIFY_URL=https://your-domain.com/api/payments/alipay/notify
```

### 3.4 隐私协议（关键）

路径：**控制台 → 小程序 → 设置 → 隐私协议**

填写隐私政策文本，需包含：
- 收集的信息类型：头像、昵称、手机号、相册、摄像头
- 收集目的：会员服务、扫码点餐、订单通知
- 信息存储与保护方式
- 用户权利（查询、删除、撤回同意）

### 3.5 功能列表签约

路径：**控制台 → 小程序 → 功能列表**

必须签约/开通的能力：

| 功能 | 说明 |
|---|---|
| 获取会员手机号 | 企业主体可开通；用于 `getPhoneNumber` |
| 支付宝会员授权 | 用于 `getAuthCode` 登录 |
| JSAPI 支付 | 小程序内支付（见第 4 节） |

### 3.6 体验版与发布

1. 支付宝开发者工具 → 上传
2. 开放平台控制台 → 版本管理 → 提交审核
3. 审核通过后 → 发布

## 4. 支付能力开通

### 4.1 微信支付

详见 [2.4 微信支付](#24-微信支付)。核心步骤：
1. 小程序后台申请开通微信支付
2. 完成商户号注册与认证
3. 配置 APIv3 密钥和证书
4. 后端 `.env` 填入商户信息
5. 确保 `ALLOW_PAYMENT_MOCK=false`（生产必须）

### 4.2 支付宝 JSAPI 支付

1. 开放平台 → 产品中心 → 搜索"JSAPI 支付"
2. 签约并关联本小程序 AppID
3. 配置异步通知地址：`https://your-domain.com/api/payments/alipay/notify`
4. 后端 `.env` 确保 `ALIPAY_APP_ID`、密钥已配置
5. 生产环境 `ALLOW_PAYMENT_MOCK=false`

> ⚠️ 支付对象为餐饮实物（面条），非虚拟餐品，不受 iOS 虚拟支付限制。

## 6. 常见驳回原因与排查

| 驳回反馈 | 排查方向 |
|---|---|
| 未配置用户隐私保护指引 | 微信后台 → 设置 → 服务内容声明，提交隐私指引并等待生效 |
| 小程序在未登录状态下应能正常浏览 | 确认首页不强制跳转登录，游客可浏览菜单（本项目扫码已静默直入菜单，若被驳回检查是否误回退旧版 index） |
| 页面存在开发调试代码入口（VConsole、测试输入框等） | 体验版不应出现"模拟一键授权/手输手机号"；确认两端 `env.js` 的 `shouldShowDevTips()` 仅在 `develop` 返回 true |
| 请在用户主动触发后再申请授权 | 检查 `onLoad`/`onShow` 中是否直接调用授权 API |
| 涉及虚拟内容支付，未使用虚拟支付能力 | 本项目为实物餐饮支付，确认支付场景为点餐 |
| 类目与实际运营内容不符 | 确认选择"餐饮"类目，上传食品经营许可证 |
| 服务器域名未配置 | mp 后台配置 request 合法域名，确保 HTTPS + 备案 |
| 页面功能不完整 | 确认所有页面可正常打开，无"开发中"占位 |
| 用户信息授权描述不明确 | 隐私指引中每个权限项都要写明具体用途（本项目会员页已有"用于累计积分、会员打折及出餐提醒"提示） |
| 内容不符合运营规范 | 检查是否有诱导分享、诱导关注等营销文案 |
